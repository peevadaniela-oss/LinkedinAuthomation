# LinkedIn Daily Routine — Pelvic Floor Edition

A ready-made Claude routine that grows your LinkedIn network among gynecologists, urogynecologists and women's health clinics, and publishes posts about pelvic floor care, every weekday.

Shared by Daniela Peeva, who has run the same routine for her own business since July 2026.

## Start here
1. Read **[SETUP-GUIDE.md](SETUP-GUIDE.md)** (or the PDF version, `Setup-Guide.pdf`). About 15 minutes.
2. Copy the `templates` folder to your computer, e.g. `Documents/PelvicFloor-LinkedIn`.
3. Fill in the templates. Fastest way: open the folder in the Claude desktop app (Code tab) and say *"interview me and fill in business-profile.md"*, then the same for each file.
4. Run it by hand twice in draft mode: *"Run dailyconnect, then dailyauthority, in DRAFT MODE"*.
5. When it looks right, paste `scheduled-task-prompt.txt` into Claude to schedule it for 9:00 every weekday.

## Important
LinkedIn's user agreement does not allow automated activity, and accounts that look automated can be restricted. Start slow (see Step 6 of the guide), keep the daily limits, and stop at the first warning. Emsella is a medical device: only claims that match its approved use, always with a source.
